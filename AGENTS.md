# Maintaining this repository

- This is a public documentation and adoption-skill repository. Do not launch Unity for documentation work.
- Keep documentation in English and user conversation in their chosen language.
- Use an isolated task branch/worktree. Keep changes within the requested scope.
- Preserve the distinction between instructions, illustrative command shapes, installed tools and validated runtime behavior.
- Keep the skill self-contained. Load detailed references conditionally; do not duplicate their content into its entry point.
- Adoption must explain feature purpose and cost, ask for a selection when missing, and preserve existing project instructions. Never imply that adopting the contract installs its dependencies.
- Keep machine-specific paths, private catalogs, credentials, game sources and private service destinations out of public files.
- Run `python scripts/validate.py`; review the full diff before committing. Push a reviewable branch when a remote is available.
- Do not claim token savings, live Unity validation or independent agent evaluation without corresponding evidence.
